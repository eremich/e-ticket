## Principles

- **One hero per job.** The card for paying, the live arrival chip for waiting. Everything else is calm.
- **Tokens only.** No raw hex, radius or font size in components. Missing a value? Add a token.
- **Two themes, two languages.** Switch both from the toolbar. Ukrainian must fit without overflow.
- **Transport is never color alone.** Icon or M, number, color: always together.
- **Props in, events out.** Components never read the app store, so they render here exactly as in the app.
